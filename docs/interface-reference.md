# Interface reference and visual direction

Updated 2026-10-12. The learner requested a colour scheme and window arrangement closer to NavAQ.

## Reference

The public [BeamworX NavAQ page](https://www.beamworx.com/navaq/) and its [remote-display illustration](https://www.beamworx.com/WP/wp-content/uploads/2020/11/remote-display-900x500.png) show a compact desktop application with light chrome, bordered panels, numeric data areas, and chart views. The [chart example](https://www.beamworx.com/WP/wp-content/uploads/2018/12/chart-view-900x500.png) shows blue water and coloured survey overlays.

These public images are historical examples and do not establish the learner's current version, menus, or saved workspace layout.

## Implemented design intent

- Light gray application workspace with compact Segoe UI text.
- Square bordered panels and pale blue title bars inspired by docked desktop windows.
- A functional view-navigation toolbar linking to existing panels.
- Sensor/setup panels beside the larger chart where space permits.
- Connection settings and the exercise check remain visible in responsive panels.
- Blue synthetic water, beige coast, magenta planned line and green received track.
- Hints and assessment remain original training features.

Panels are arranged with responsive CSS; they are not draggable docking windows. Toolbar items navigate the page and are not claimed to reproduce NavAQ menus. The SVG chart is an educational illustration, not a navigation chart or actual survey data.
